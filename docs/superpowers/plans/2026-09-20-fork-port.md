# Fork recovery plan

Goal: recover OpenA's useful CLI, bootloader packaging, serial checks and UPDATE.APP extraction with attribution and hardware-free validation.

Selected approach: retain the fork commits, then fix concrete failure cases. A wholesale replacement loses attribution; copying only the extractor leaves the fork's useful CLI and packaging behind.

1. Add regression tests for CLI help and argument errors, serial timeout/failure propagation, checksum integrity and safe extraction from a different working directory.
2. Correct only the affected boundaries: explicit commands, bounded archive reads, confined output names, verified bootloaders, exact serial acknowledgements and fastboot interface selection.
3. Preserve the original authors and list omitted decryption/GUI features. Run unittest and compile checks, then publish a reviewable PR without merging or device access.
